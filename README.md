# Война за Средиземье

Фанатская настольная стратегия по миру Толкина на карте территорий из мода Edain для BFME.

- `index.html` — подробная карта территорий
- `krupnye.html` — вариант с крупными территориями
- `igra.html` — сама игра: онлайн по ссылке-комнате (каждый со своего устройства) или на одном устройстве

Онлайн-режим работает без сервера, через WebRTC (PeerJS). Хост держит страницу открытой во время игры.
